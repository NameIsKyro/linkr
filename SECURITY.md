# Security

Linkr runs locally inside Obsidian and does not make network requests or collect telemetry.

To report a security issue privately, contact the maintainer through the contact options on the [NameIsKyro GitHub profile](https://github.com/NameIsKyro). Please do not publish sensitive vulnerability details in a public issue before the maintainer has had a reasonable opportunity to investigate.

For ordinary bugs and feature requests, use the [Linkr issue tracker](https://github.com/NameIsKyro/linkr/issues).
